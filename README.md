## ⚡ Quiénes somos

**R3ZON** es un estudio de software de Bilbao que digitaliza, optimiza y escala **autónomos, pymes y empresas**.
Construimos herramientas propias y reutilizables —CRM, facturación, reservas, inventario, dashboards— y las adaptamos a cada cliente. Sin plantillas genéricas, sin intermediarios: hablas directamente con quien escribe el código.
